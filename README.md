# Flight Management System

## 📌 Project Overview

This is an academic project developed using **Python and MySQL** to manage flight-related information and perform database operations.

## 🛠️ Tools & Technologies

- Python
- MySQL
- SQL

## 🎯 Project Features

- Add and view flight details
- Add and view passenger details
- Search flights by source and destination
- Book flights
- Manage bookings
- Delete flight and passenger records
- Perform database operations through Python

## 📂 Project Files

- `Flight_Management.py` — Python program for the flight management system
- `flight_management_passenger_flights_bookings.sql` — SQL file containing the database tables and sample data

## 💡 What I Learned

Through this project, I practiced:

- SQL and relational database concepts
- CRUD operations
- Connecting Python with MySQL
- Managing flight and passenger data
- Working with database-driven applications

## 👋 About

This was an academic project created to strengthen my **Python, SQL, and database management skills**.
